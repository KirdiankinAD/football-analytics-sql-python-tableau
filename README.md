# ⚽ Football Match Analytics — SQL Deep Dive (PostgreSQL)

Исследование около **95 000 футбольных матчей** из 18 лиг и кубков (2000–2020‑е) средствами чистого SQL: от нормализации «грязного» CSV до проверки футбольных гипотез статистическими функциями PostgreSQL.

Проект состоит из трёх частей: **SQL** (эта часть) → **Python** → **Tableau**.

## TL;DR — главные находки

- **Домашнее преимущество реально, но удивительно ровное**: win rate хозяев ≈ 0.43–0.47 почти во всех крупных турнирах (разброс ~4 п.п.).
- **Красная карточка — самый сильный и универсальный эффект**: снижает win rate команды во всех 16 турнирах; в АПЛ почти вдвое (0.38 → 0.20).
- **«Трибуна давит на исход» — слабый эффект**: корреляция посещаемости с победой хозяев есть, но \(R^2 = 0.014\) — посещаемость объясняет ~1.4% исхода.
- **«Инфляции голов» со временем нет**: результативность колеблется ±20% от сезона к сезону без устойчивого тренда.
- Итальянские топ‑клубы формируют самые частые пары соперников (7 из топ‑10).

Полный набор из 19 запросов (включая self‑join для личных встреч, анализ камбэков и конверсии ударов) — в [`sql/queries.sql`](sql/queries.sql).

## Стек и данные

- **СУБД:** PostgreSQL.
- **Исходные данные:** ~95 384 строки, 69 столбцов, смешанный разделитель `;`, локализованные десятичные, проценты в текстовых полях.
- **ETL:** staging‑таблица (`TEXT`) → очистка через regex/`UPDATE` → типизированная загрузка через `INSERT ... SELECT` с `CAST`.
- **Схема:** 5 таблиц — `leagues`, `teams`, `stadiums`, `matches`, `match_team_stats` (long‑формат: одна строка = одна команда в одном матче, с флагом `is_home`).

```text
leagues (id, country, league_name)
teams (id, team_name)
stadiums (id, stadium_name, capacity)
matches (id, league_id, home_team_id, away_team_id, stadium_id,
         season_year, date_day, date_month, home_score, away_score,
         first_half, second_half, attendance)
match_team_stats (id, match_id, team_id, is_home,
                   expected_goals_xg, ball_possession, red_cards, shots_on_goal, ...)
```

**Техники:** агрегация · многоуровневые CTE · оконные функции (`ROW_NUMBER`, `LAG`, `SUM() OVER`, `RANK`) · pivot через условную агрегацию · self‑join · статистические агрегаты (`CORR`, `REGR_SLOPE`, `REGR_R2`, `PERCENTILE_CONT`, `STDDEV_SAMP`).
